When it opens

Once, the first time you touch the desk after ten minutes without input, if an agent changed state while you were gone. Otherwise it waits in the bell.

What it holds

Only what changed since you left: waiting first with how long, then what stopped, then what finished. Working agents are a count, not rows.

What it does

A row opens its pane. Answers still happen one card at a time; the recap has no buttons that act for an agent.
