What it takes
1A workspace is a composition. sola-river already shows only the windows in its last composition and River hides the rest, so switching sends a different set. Zones and the gap grid are per workspace.
2Apps open a window per workspace. The browser is one window today, and so are Projects and Mail. One engine, many windows: a page on Sola and a page on Mail share one browser process, one cookie jar, one vault.
3The rename first. sola-workspaces → sola-projects before any workspace code, so the word never means both. It reopens a locked model: crate, window, the workspaces call owner, solactl and MCP names, config path, skills.
4The desks idea's panel model waits. Shell-owned tab groups across apps stay parked; this needs none of it. The 2026-10-12 idea's sidebar becomes this bubble.
