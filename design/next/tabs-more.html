The apps lose their lists · 1:1
What it takes
1A tab is a window. Each page, shell, and agent session is its own toplevel; the engines stay one process each (one browser, one cookie jar, one vault). sola-river shows each zone's chosen window and leaves the rest out of the composition, which River already hides.
2The shell owns the list. Zone, order, and what shows live in the shell per workspace, with a restore token for each tab: a URL, a working directory, a tmux session. Apps keep their own session data.
3Apps drop their strips. The browser's vertical tabs and its colored groups, the Projects rail, the terminal's tabs. Tool anatomy stays: the location bar, Mail's list and reader, devtools.
4This is the desks idea's panel model. The 2026-10-12 idea put a tab strip on each group; here the one bar is every zone's strip. It is the windowing-model change that idea flagged, and it replaces zones-as-snaps.
Yours to pick
AWhere Projects' projects go. A workspace bound to a project (agents spawned on Sola use the Sola repo), or a project label on each agent tab. Proposed: bind a workspace to a project.
BThe browser's groups. Drop them, since zones and workspaces group now, or nest groups inside a zone in the bar. Proposed: drop them.
COrder inside a zone. As you arrange it, mixed, or sorted by kind. Proposed: as arranged.
DWhere a new tab lands. The focused zone, or the zone its kind last used. Proposed: the focused zone.
