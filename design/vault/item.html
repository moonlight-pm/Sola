03A record, and editing it
The record is Settings' grouped rows: label over value on the left, its tools on the right — copy on every field, reveal on secrets, open on a website. The one-time code is the largest thing on the sheet, with its time left as a ring. Fill is the one primary, at the foot. Edit turns the same groups into fields in place, so nothing moves.

Notes
Fill once, at the foot. Today the record has Fill in its head and again on the authenticator. Here Fill fills the login and its code together (the code also goes to the clipboard, as Bitwarden does — a decision for you).
Time left is a ring. A 30 s arc in secondary ink that turns warning in its last five seconds, with the number inside. The code is 20 px mono, grouped in threes.
Edit keeps its place. The groups do not move; values become fields. A changed field shows a dot by its label, because Save writes only those.
Websites show their match. Each address has its match type beside it (Domain, Host, Starts with, Exact, Regular expression, Never), so you can see why a login is offered on a page.
